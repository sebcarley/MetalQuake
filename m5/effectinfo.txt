// m5/effectinfo.txt -- SEPTEMBER S5. Explosions and teleports.
//
// PARTIAL FILE BY DESIGN. CL_NewParticlesFromEffectinfo falls through to the
// hardcoded CL_ParticleEffect_Fallback for any effect NOT named here, so every
// effect this file does not mention keeps working exactly as it did.
//
// BUT THE FALLBACK IS ALL-OR-NOTHING PER NAME. `found = true` is set the moment
// any block names an effect (cl_particles.c:1671) -- BEFORE the underwater
// filter -- so naming TE_EXPLOSION deletes ALL FOUR of its hardcoded outputs at
// once: the decal, the dlight, the lightmap stain and the 512 sparks. Every one
// has to be re-supplied below or knowingly written off. See the stain note.
//
// FIVE RULES THIS FILE OBEYS, each of which is a silent failure if broken:
//
//  1. A WRONG-ARITY LINE ABORTS PARSING OF THE WHOLE REST OF THE FILE.
//     checkparms(n) ends in `break;` and the only enclosing loop is the LINE
//     loop, so one bad line prints one console message and every block below it
//     never exists. `size` takes 2 arguments, not 3 (sizeincrease is separate);
//     `alpha` exactly 3; `rotate` exactly 4; underwater/notunderwater must be
//     ALONE on their line.
//  2. `type` MUST BE THE FIRST LINE OF A BLOCK -- its handler overwrites both
//     blend and orientation, so a `blend` written above it is discarded.
//  3. `type smoke` IS ADDITIVE. Dark smoke on it adds almost nothing and can
//     never occlude, which is the exact complaint this file exists to fix.
//     `blend alpha` AFTER `type smoke` is the whole cure. `blend refract`
//     (BEAUTY A5) makes the layer displace the frame behind it by its own
//     coverage -- for a ring cell, a shockwave; the layer is never spawned
//     while cl_particles_refract is 0.
//  4. TEXTURE CELLS. This engine writes art into 0-32, 34 and 60-63 ONLY (the
//     setuptex calls in cl_particles.c; 34 is the M5 shotgun shell casing,
//     SEPTEMBER S6). Cells 33 and 35-59 are memset to opaque WHITE -- 33 on
//     purpose, it is the GLQuake square particle -- so a stray index draws a
//     solid white square; and an index >= 64 WRAPS modulo 64 rather than
//     erroring. 35 is a crisp white disc (m5_dust), 36 a thin ring (the
//     shockwave), 37 the muzzle FLASH (a starburst), 38 the SPARK STREAK (a
//     thin hot line along the stretch axis -- for `type spark` layers), 39 the
//     EMBER (a hard bright bead with a rim), 40 the blood DROPLET (inverted, for
//     `type blood` only). Usable here: 0-7 smoke puffs, 8-15 bullet decals, 34 a
//     brass hull, 36 ring, 37 flash, 38 streak, 39 ember, 62 bubble, 63 the
//     plain dot. cl_particles_texsize 256 makes every one of them sixteen times
//     finer without touching this file. BEAUTY A2, 2026-09-16: the spark and
//     ember layers below moved from 63 to 38 and 39; put 63 back for the blob.
//     DO NOT copy texture indices out of another mod's effectinfo -- they point
//     into that mod's own particlefont atlas, not this one.
//  5. NEVER define `effect SVC_PARTICLE`. Naming it kills the fallback that
//     carries the legacy particle() builtin's count-1024 explosion reroute and
//     the blood hack, in every mod and mission pack.
//
// DELAY (engine keyword added 2026-09-02, SEPTEMBER S5): `delay min max`,
//     seconds after the effect fires before the layer's particles appear --
//     no physics, no fade, no draw until then; lifetime and spin start at the
//     delayed moment. What lets the smoke rise AFTER the flash. Two args.
// COUNTS: `count` is multiplied by cl_particles_quality (Seb runs 3);
// `countabsolute` is NOT. Anything whose brightness must not change with the
// quality setting -- the flash, the fireball core -- uses countabsolute.
//
// Iterate without a rebuild: `cl_particles_reloadeffects` in the console.
