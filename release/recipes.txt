# release/recipes.txt -- the recipe .cfg files the PUBLIC download ships, by name.
#
# A recipe ships because it is NAMED here, never because it was not excluded
# (RELEASE.md's allow-list rule; REVIEW.md 0.9). release/check-recipes.py fails when
#   - a [ship] name is not a file in m5/ or (in the tree) is not tracked: the recipes
#     are force-added past .gitignore's /m5/* -- git add -f m5/<name>.cfg;
#   - docs/GUIDE.html, docs/MANUAL.html or SETTINGS.md names a recipe that is neither here nor under
#     [not-shipped] (config.cfg is the profile the build writes; default.cfg is id1's);
#   - a shipped recipe tells the player to exec one that does not ship;
#   - a built packs/m5 carries any .cfg that is not listed here.
# test/docsync.py runs the tree check (so smoke does); release/make-release.sh runs both.
# One name per line; a [not-shipped] line gives its reason after the name (spaces, not tabs).
